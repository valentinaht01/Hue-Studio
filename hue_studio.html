01 / Overview

Una identidad construida desde la intención.

HUE STUDIO nace como un estudio independiente de diseño gráfico y dirección creativa. La identidad busca equilibrar una estética contemporánea con una comunicación clara, creando un sistema visual flexible, reconocible y con personalidad propia.

02 / Logo

Una identidad simple.

El sistema de logotipo parte de una construcción tipográfica limpia y directa. Su estructura permite que la marca funcione tanto en formatos editoriales como digitales.

03 / Typography

Tipografía como lenguaje.

La tipografía funciona como uno de los elementos principales de la identidad. La combinación entre una sans serif contemporánea y una tipografía monoespaciada crea contraste entre lo editorial y lo técnico.

04 / Color

Un color que identifica.

El violeta funciona como el elemento cromático protagonista de HUE. Una base neutra permite que el color aparezca con fuerza y construya reconocimiento dentro del sistema visual.

05 / Visual System

Un sistema pensado para moverse.

La identidad se construye a partir de contraste, escala, espacio y jerarquía tipográfica. Estos elementos permiten que HUE mantenga una presencia reconocible en diferentes formatos y contextos.

06 / Applications

La identidad en acción.

Aplicaciones del sistema visual en medios digitales, redes sociales, piezas editoriales y diferentes puntos de contacto de HUE STUDIO.
