# HUE STUDIO

### Creative Studio · Branding · Digital Design

HUE STUDIO is an independent creative studio focused on **visual identity, digital design and creative direction**.

This website was designed and developed as a digital space to showcase the studio's work, visual language and creative approach.

---

## ✦ About the Project

The HUE STUDIO website combines **graphic design and front-end development** to create a clean, expressive and contemporary digital experience.

The project focuses on:

* Visual identity
* Creative direction
* Digital experiences
* Responsive web design
* Portfolio presentation

---

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript**
* **Responsive Design**

---

## 🎨 Design Direction

The visual identity is built around a minimal palette of **black, off-white and violet**, creating a balance between editorial design and contemporary digital aesthetics.

The website prioritizes:

**Typography · Composition · Contrast · Motion · Visual hierarchy**

---

## 📱 Responsive Design

The website was designed to provide a consistent experience across:

* Desktop
* Tablet
* Mobile
